# My experience trying Proxmox
I've been using Proxmox in my humble homelab for about 8 months. A colleague of mine managed to push my interest in Proxmox and enterprise virtualization software over the edge. I hadn't really felt the urge to actively install Proxmox and try it out until October 2025, when I was following along with some cluster stuff with a colleague. While he was working hard setting up some virtual machines, I was sitting there amazed at the convenience of the Proxmox Virtual Environment.

## A Proxmox Test Server (or is it?)
A little while later I finally decided to give Proxmox a try on a test machine I had laying around; a very cute HP ProDesk 600 G3 SFF (try saying that three times fast). The specs? A 7th generation Intel Core i5-7600 with 32GB of DDR4 memory and 512GB of SATA SSD storage. Your first thought probably goes something along the lines of "those specs are horribly insufficient for a functional Proxmox server." Don't worry, I thought so too. Good thing this server was meant to be a test, a throw-away project that would be discarded within the first week of its existence.

That, however, wasn't really the case. I set up Proxmox, installed a fresh copy of Windows XP Professional SP3 (as you do) for the first VM, and started playing around with it. The first thing I noticed is how damn speedy everything was. Running regular Debian or Fedora with KVM enabled does not give me the same amount of performance I was getting here. Granted, I was only testing Windows XP, but it was still a lot more performant than I expected. Suddenly, I was even more intrigued. After giving Windows 7 Ultimate SP1 a try (yes, I'm crazy), and being once again amazed at the performance I was able to squeeze out of the system, I was really hesitating to discard this Proxmox test server to build a proper server a few months later. These initial tests already demonstrated that this test server would be more than capable of running microservices like my portfolio in small Debian VMs, so I was doubting discaring this thing.

I ultimately decided to test a little further. Not with new VMs, but just messing around with the configuration of the existing two virtual machines I had already installed. A day or so later, I decided to deploy the cute little HP ProDesk in my homelab until I found a beefier system to run Proxmox on. That hasn't happened yet.

## Proxmox for services
My single Proxmox server has been responsible for a great number of services over the past eight months. It started with a Windows 10 VM so that I could work on school stuff remotely, then I deployed my (then new) [Cortex 98](https://github.com/IzKuipers/Cortex98-v2) project on PROX103 (deb-retro). So yes, the first real service I ever deployed on Proxmox was a PHP-powered website built for Internet Explorer 5. I'm sorry, it gets worse. After deploying Cortex 98, I moved on to Windows Server 2008. It seemed like a fun time to finally get a proper Windows Server installation running for my retro hardware, including Microsoft Exchange and Active Directory Domain Services. Using Windows Server 2008 meant that I could connect everything from Windows 98 up until Windows 11 to that server no problem. I have a lot of network-enabled retro hardware at home.

Since the initial run of deployments with Windows Server 2008 and Cortex 98, I moved on to actually _moving_ services from the homelab to Proxmox VMs. The portfolio you're reading ths on, is on PROX105 (deb-hosting). Don't believe me? Open Developer Tools, go to the Network tab, refresh the page, and look at the response headers of the webpage. I also moved Uptime Kuma, Eureka and more to the server without issue. All it took was setting up debian, cloning the project, configuring networking, etcetera.

The final thing I installed on Proxmox to date is PiHole on PROX109 (deb-pihole). this VM is responsible for, well, hosting PiHole. Paired with my Wireguard, PiHole allows me to remove the great majority of ads from my phone, no matter where I am. It's made reading news articles about tech and stuff actually possible on my phone (without employing something like Firefox Reading Mode), which truly is the stuff of dreams.

## In conclusion
Proxmox is great. I've had a great amount of fun getting to know the ins and outs of Proxmox VE over the last 8 months, and I'll keep experimenting with it for the forseeable future. I still want to build a second Proxmox 'test' server so that I can put them together in a Proxmox Cluster, just because it sounds cool. That's really why I do everything that I do in IT: "sounds like fun, let's do it."
